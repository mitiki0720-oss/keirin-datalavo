## 1-b) ちゃりごんの物理法則（Physical Constants）

**遠心力バイアス（カント・Rの効き方）**  
- 向心（≒遠心）力：**F = m·v² / r**（速度vが2倍 → 力は4倍）
- “理想バンク”近似：**tanθ = v² / (r·g)**
- 宇都宮は最高カント **25°47′44″（25.80°）** と“浅め”の部類 → コーナーで速度を載せにくく、**外並走の消耗が出やすい**。
- 実戦メモ：直線勝負が成立しやすく、**「交わしの交わし」**（番手でも安泰じゃない）が起きやすい。

**直線係数（数字 vs 体感）**  
- 数字：みなし直線 **63.3m**（500mとして長め）
- 体感のズレ要因：
  - カント浅め → 立ち上がりで伸び差が出る
  - 風で相対風速が変わり“直線が伸びる／縮む”
  - 隊列が長いほど仕掛け位置が早まりやすい
- 2009年改修で **67.9→63.3** 短縮＝昔よりは先行が動きやすいが、依然「差しが間に合う」レンジ。

**重力・抵抗（重い／軽い）**  
- g：**9.80665 m/s²**（基準）
- 空気抵抗：**D = 0.5·ρ·V²·Cd·A**（ρ：空気密度、V：相対風速）
- ρ目安：**1.225 kg/m³**（海面上）
- 宇都宮はスタンド吹き抜け等で **1〜2コーナー〜ホーム側に風が抜ける** ことがあり、向かい風は“重く”、追い風は“軽く”出やすい。

## 2) 風・天候 → 展開の法則（その場のクセ）

### 2-1) 風向ごとの影響（バック基準）

- **向かい風**：
  - 先頭（逃げ／番手）が正面から受けて踏み直しが効きづらい → **差し・3番手絡み（ズブズブ）** が増えやすい。
  - 強い日は外捲りが届きづらいこともある（仕掛け遅れ厳禁）。
- **追い風**：
  - 直線でスピードが落ちにくい → **先行ラインの残り目（逃げ残り／番手残り）** が増えやすい。
  - 「バック向かい風×ホーム追い風」セットは、バックで捲りが決まれば押し切りやすい。
- **横風**：
  - **バック左横風**：内側の先行ラインが消耗 → **外捲りが通りやすい**。
  - **バック右横風**：外を回すラインが風を受けやすく、捲りの伸びが鈍る → **番手差し／内の残り** 注意。
- **無風時**：
  - 「差し基準」は変わらないが、隊列・脚力通りに決まりやすい。

**目安**：風速が **3m/s** 付近から「買い目を変える価値」が出やすい。

### 2-2) 時間帯別バイアス

- **モーニング**：差し＞捲り＞逃げ。平均配当は比較的低め（ただし紐は散る）。
- **デイ**：差しが主役。カテゴリ内で「2着が割れる」帯がある（A級）。
- **ナイター**：差し主役＋逃げ残りも出る。S級は荒れ帯（万車率高め）。
- **ミッド**：A級7車は母数多めで万車率も高い。短い周回・位置取り優先で、紐抜け（3着散り）警戒。
- **Gレース**：データ未掲載

## 6) 並び・仕掛けの読み（場の実戦則）

**ライン戦の傾向（全231R｜集計）**
- ライン構成の最多：**3-2-2（96R／41.6%）**、次点：**3-3-1（42R／18.2%）**。
- 1着の所属ライン：**3車ライン52.0%／2車32.5%／4車以上12.6%／単騎3.0%**。
- ライン決着：**1-2同ライン 約60%**、**1-2-3同ライン 約22%** → **3着は勝ちライン外がデフォ（紐抜け注意）**。
- 1着のライン内ポジション：**先頭57.1%／番手39.8%／3番手3.0%** → 宇都宮は **番手差しが主軸**。
- 単騎の絡み：**単騎1着3.0%／2着4.3%／3着10.4%** → 単騎は「3着穴」で効く。

**S取りの有利枠／型**
- 勝ち馬が「並びの先頭ライン」から出た割合：**53.7%（124/231R）**。
- 先頭ラインが勝った時の **1-2同ライン率66.9%（83/124R）** → 前受け濃いラインは番手まで残りやすい。

**仕掛けポイント**
- 基本は「差し基準」：番手差し・追い込みが間に合うレンジ。
- ただし横風・向かい風が強い日は、仕掛け遅れ＝外捲り不発になりやすい → **早めの主導権／内の差し**を評価。
