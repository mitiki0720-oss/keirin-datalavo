## 1-b) ちゃりごんの物理法則（Physical Constants）

**遠心力バイアス（カント・Rの効き方）**  
- バンク（カント）は、コーナーで発生する「外へ飛ばされる力」を傾斜で受ける設計。
- 目安式（摩擦を無視した基本形）：tanθ = v^2 / (r g)（θ=バンク角、v=速度、r=曲率半径、g=重力加速度）。
- 弥彦はカントがややキツめと言及され、コーナーで速度を乗せやすい＝捲りも打ちやすい一方、外々を回すほど（大外捲りほど）負荷が増え、失速リスクが上がる前提で組む。

**直線係数（数字 vs 体感）**  
- みなし直線 63.1m（400mバンクでも長め）→ 最終直線の“追い込み猶予”が長く、差し／捲りが届きやすい。
- ただし弥彦は「最終コーナー〜直線への緩和（曲線のつながり）」がキツいと言及があり、外を回すほど速度を乗せ切れず“体感直線が短くなる（外伸びが鈍る）”ケースがある。

**重力・抵抗（重い／軽い）**  
- 「重い＝ペダルが重い」状態。路面の湿り・低温でタイヤの転がりが悪い等で抵抗が増える。
- 弥彦は積雪地帯でオフ明け（春先）にバンク張替えが行われ、“弥彦は重い”と言われることがある（新しい走路はタイヤ負荷が増える、という整理）。
- 重い日は先行が脚を使いやすく、番手差し／追い込みが浮上しやすい前提で、ラインの番手〜3番手評価を上げる。

## 2) 風・天候 → 展開の法則（その場のクセ）

### 2-1) 風向ごとの影響（バック基準）

- **向かい風（バック向かい風が出やすい：西〜北西系）**：
  - バック〜3Cで踏むと風をモロに受けやすく、捲りが伸び切りにくい。
  - 「逃げライン残り → 番手差し」になりやすい。3番手までズブズブ警戒。
  - 仕掛けは“遅め捲りの一撃”より、番手の差し・追込み寄りで組む。

- **追い風（バック追い風：南〜南西系）**：
  - 2Cからの早めカマシ／捲りが決まりやすい（主導権が取りやすい）。
  - ただしホーム〜直線は向かい風になりやすく、先行が最後にタレる→番手差し本線。
  - 「先行1着固定」は危険。番手〜3番手厚めが基本。

- **横風**：
  - 風よけが効く“隊列の中（番手・3番手）”が相対的に得。
  - 大外を回す捲りは失速しやすいので、外捲り一本の買い方はリスク。
  - 横風が強い日は「位置取り・ラインの厚み」を優先。

- **無風時**：
  - 直線の長さが素直に効き、差し／捲りの“脚の差”が出やすい。
  - 「番手差し＋別線の先頭（捲り）」の二段構えが事故りにくい。

> 風向の表記ルール（固定）：**ホーム側＝西側（＝バック側は東側）**。風向は「○○風」＝その方位“から”吹く（例：南風＝南→北）。

### 2-2) 時間帯別バイアス

- **モーニング**：データ未掲載
- **デイ**：番手差し軸が基本。2着は同一ライン優勢、3着は別線・単騎混ざり前提。
- **ナイター**：日中より風が落ち着きやすく差し／捲りが安定しやすい。冷え込みで“重い”日は先行が脚を使い、番手差し寄り。
- **ミッド**：風は弱まりやすいが、冷え込み・湿り（雨上がり等）で“重い／伸びない”日が出やすい。直線勝負→番手・追込みの評価UP（3着ズブズブも残す）。
- **Gレース**：多分戦で紛れやすい。3着が穴化しやすいので“別線・単騎・外”を厚め。

## 6) 並び・仕掛けの読み（場の実戦則）

> 集計対象：並びと結果が揃っている 264R（表記崩れ・欠損はスルー）。

**ライン戦の傾向**  
- **7車（217R）**：3分戦が主流（3ライン=75.1%／4ライン=17.1%／2ライン=7.8%）
- **9車中心（43R）**：4分戦が主流（4ライン=81.4%）
- **最大コマのラインが強い**：勝ち筋の **71.2%** が「最大コマ（最長ライン）」から発生。
  - 3車ラインがあるレースでは、**3車ラインが勝ち 65.1%**（229R中149R）。
- **勝ちの型がハッキリ**（264R）
  - **番手（ライン2番手）の1着：50.0%**（132R）
    - そのうち **差し：97%**（128/132）＝「番手差し」が基本形。
  - **先頭（ライン1番手）の1着：45.1%**（119R）
    - 内訳は「捲り（先頭）」「逃げ切り」が中心。
- **ライン決着は2着までが濃い**
  - 1-2着が同一ライン：**63.4%**（262R中166R）
  - 1-3着が同一ライン：**26.0%**（262R中68R）
  - つまり **3着は別線混ざりが多数派（約74%）**。
- **単騎は“頭”より“紐”**
  - 単騎（1人ライン）があるレースで、単騎の **1着は1.7%**（2/115）
  - 一方で **3着は13.0%**（15/115）→ 3着穴として拾う価値が高い。

**S取りの有利枠／型**  
- 枠（車番）傾向が強いカテゴリでは、**内枠（1-3）の主導権が取りやすい**（特にミッドA）。
- 実戦的には「先頭が主導権 → 番手が差す（差-逃が最多）」が多い。
  - **“S取り→前受け→主導権” を取れるラインの番手**を最優先評価。
  - ただし 9車の多分戦（4分戦以上）は番手勝ちが増えるため、**番手軸＋3着に別線（単騎含む）**が事故りにくい。

**仕掛けポイント**  
- バック向かい風（西〜北西）の日：捲りが伸び切りにくい前提で、番手差し／ズブズブ寄りに寄せる。
- バック追い風（南〜南西）の日：早め仕掛け想定でも「最後の番手差し」を消さない。

## 7) 予想フロー（この場での基本）

> 10点でも18点でも、この場で守りたい「組み立ての型」をまとめる。

### 7-1) 事前チェック

- **カテゴリ確定（最優先）**
  - **ミッドA（7車）**：1着が内枠1-3に強烈に寄る → 1着軸は基本1-3から外さない。
  - **デイA / ナイターA（7車）**：内寄りだが外も勝つ（外1着が2割前後）→ 1着候補は1-5中心＋穴で6-7まで。
  - **デイS（7車）**：内〜中が中心 → 3着の「4・2」が抜けやすい。
  - **G（9車）**：中〜外の勝ちも普通に出る → 枠固定はしない。

- **車数（7車／9車）とライン数**
  - 7車は 3分戦が主流（約75%）。
  - 9車（G中心）は 4分戦が主流（約81%）。

- **最大コマ（最長ライン）確認**
  - 勝ち筋の中心は最長ライン（約71%）。
  - 3車ラインがあるなら、そのライン勝ちが強い（約65%）。

- **風（条件分岐）**
  - バック向かい風（西〜北西）→ 捲り一本買いをしない（番手差し／ズブズブ寄せ）。
  - バック追い風（南〜南西）→ 早め仕掛け想定でも「最後の番手差し」を残す。

- **1番人気・ライン構成（飛び方）**
  - 1番人気（最低オッズ目）はカテゴリ別に **飛ぶ確率が80%超**（※Gは95%超） → “本線が崩壊する”前提で3着設計。

### 7-2) 組成ルール（例）

- **本命ゾーン**：
  - 基本は **番手（ライン2番手）を1着軸**（番手差しが最頻）。
  - 例外：ミッドAは「内枠1-3」優先。G（9車）は軸2枚（番手＋別線自力）を持つ。

- **2着ゾーン（ライン優先）**：
  - 1-2同一ラインが63% → 2着は原則「同一ライン」から作る。

- **別線ゾーン（紐抜けケア）**：
  - 1-3同一ラインは26% → 3着は別線混ざりが多数派。
  - 3着に「別線自力」「ライン3番手」「単騎」を必ず混ぜる。

※細かい10点／18点のルールは、予想キャンバス側に詳細記載。
