## 22）脳（解釈）

### 役割

| 主              | 副             |
| -------------- | ------------- |
| 自在（捲り〜差しの勝ち切り） | 番手〜好位からの3着内回収 |

### 数字から言える傾向（断定しすぎない）

- 直近4ヶ月スナップショットでは「捲り優勢（捲4／差1）」で、基本は**縦の破壊力**が核。
- B=3/S=1：自分で踏む回もあるが、番組次第で**番手〜好位**も織り交ぜるタイプ。
- 3連対率が高く、**3着内の安定が強い**（相手関係次第で頭厚め⇄2-3着寄せ）。

### 強み／弱み／リスク

| 区分  | 内容                                                    |
| --- | ----------------------------------------------------- |
| 強み  | ①縦のスピードで捲り切れる（主戦）／②番手でも仕事＋差しで拾える／③3着内の安定度が高く“軸”にしやすい  |
| 弱み  | ①単騎や包まれで仕掛け遅れになると取りこぼしが出る／②相手が超先行で隊列が崩れると位置取り勝負になりやすい |
| リスク | 当日気配が重い・欠場明け・病欠明けは評価を一段落とす（初日で判断）                     |
